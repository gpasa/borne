Preparing PC games

Borne doesn't read installers or discs: it reads the data files of an installed game. This page explains how to get them from your copy, which files to copy and where to put them. You only do it once per game.

The idea

A PC game is made of a Windows or DOS program (.exe, .dll), which is of no use on a Mac, and of data files (levels, graphics, sounds): .wad, .pak, .pk3, .pk4, .grp… Borne's engines read the latter. So you just copy them, keeping the name of their folder when they have one (id1, baseq2, baseq3…).

Copying the rest as well does no harm, Borne ignores it; but a folder with only the data is lighter and tidier.

The layout to aim for

Create a folder for your PC games, for example PC Games on your external drive, with one subfolder per game. Subfolder names are up to you; only the data files and folders inside matter. Upper and lower case don't matter either.

PC Games/
├── Doom/                       doom.wad, doom2.wad, tnt.wad, plutonia.wad,
│                               heretic.wad, hexen.wad, strife1.wad…
├── Quake/
│   ├── id1/                    pak0.pak, pak1.pak
│   ├── hipnotic/               pak0.pak   (Scourge of Armagon)
│   └── rogue/                  pak0.pak   (Dissolution of Eternity)
├── Quake II/
│   ├── baseq2/                 pak0.pak, pak1.pak, pak2.pak, players/, video/
│   ├── xatrix/                 pak0.pak   (The Reckoning)
│   ├── rogue/                  pak0.pak   (Ground Zero)
│   └── ctf/                    pak0.pak   (Capture The Flag)
├── Quake III Arena/
│   ├── baseq3/                 pak0.pk3 … pak8.pk3
│   └── missionpack/            pak0.pk3 … (Team Arena)
├── Quake 4/
│   └── q4base/                 pak001.pk4 … pak022.pk4, zpak_english.pk4
├── Doom 3/
│   ├── base/                   pak000.pk4 … pak008.pk4
│   └── d3xp/                   pak000.pk4, pak001.pk4   (Resurrection of Evil)
├── Return to Castle Wolfenstein/
│   └── Main/                   pak0.pk3, sp_pak1.pk3 … sp_pak4.pk3
├── Wolfenstein 3D/             VSWAP.WL6, GAMEMAPS.WL6, MAPHEAD.WL6, AUDIOT.WL6…
├── Spear of Destiny/           VSWAP.SOD, GAMEMAPS.SOD… (and .SD2, .SD3)
└── Duke Nukem 3D/              DUKE3D.GRP

Then, in Borne: Settings → Jeux PC → Ajouter un dossier… (Add a folder) and choose PC Games. That's it: each game appears in the sidebar.

Where to find the files

A Steam version

These are Windows games: Steam for Mac shows them in your library but won't install them. Install them with Steam on a Windows PC (yours, a friend's, a virtual machine), then in the Steam library: right-click the game → Manage → Browse local files. The folder that opens (usually …\Steam\steamapps\common\<game name>) holds the data described below.

Steam versions are already up to date: Quake III, Doom 3 and Quake 4 don't need id Software's updates.

A GOG version

Two options:

  • On a Windows PC: install the game with GOG Galaxy or the offline installer, then copy the installation folder (by default C:\GOG Games\<game name>).
  • Directly on the Mac, without Windows: download the offline Windows installer from your GOG account (setup_….exe, plus its .bin files if any, kept next to it). The free tool innoextract extracts the files. In Terminal: 
    brew install innoextract
cd ~/Downloads
innoextract setup_quake_the_offering_*.exe
    The game files appear in an app folder (or at the top of the folder): copy the data from there. This needs Homebrew; the most recent GOG installers may not open with the current innoextract: use a PC then.

An original CD or DVD

Insert the disc, or double-click its image (.iso): macOS shows it as a disk. Two cases:

  • The data is visible on the disc, often in a Setup/Data folder or at the top (for example Setup/Data/base for Doom 3, Setup/Data/q4base for Quake 4): just copy it.
  • Only an installer is visible (setup.exe, .cab or .msi files): the data is compressed inside. Install the game on a Windows PC, then copy the installed folder (usually in C:\Program Files or C:\Program Files (x86)).

An original disc often predates the game's last update. For Quake III, Doom 3 and Quake 4, Borne offers the official update at first launch: copy the disc's files as they are.

Copying to the Mac

Use a USB stick, an external drive or the network (Finder → Go → Connect to Server, smb:// for a Windows share). Copy whole folders (id1, baseq2…) rather than their contents, to keep their names. The files can then stay on an external drive: Borne never changes them.

Game by game

What to copy from the game's installation folder, and where to put it in your PC games folder. When in doubt, search for the file name in the Finder (⌘F in the game's folder).

Doom, Doom II, Final Doom, Heretic, Hexen, Strife

Copy the game's .wad files (doom.wad, doom2.wad, tnt.wad, plutonia.wad, heretic.wad, hexen.wad, hexdd.wad, strife1.wad with voices.wad) into a single Doom folder. In the Steam and GOG versions they sit in the game's folder or in a subfolder such as base or rerelease. Your mods (.wad, .pk3) go in the same folder.

No copy of Doom? Freedoom, free and complete, downloads from Borne (Settings → Données).

Quake and its add-ons

Copy the id1 folder (pak0.pak and pak1.pak), and if present hipnotic and rogue, side by side in a Quake folder. The 2021 Steam version keeps the original game in these folders; its rerelease folder isn't needed. An id1 without pak1.pak is the demo version.

Quake II and its add-ons

Copy the baseq2 folder (at least pak0.pak; also pak1.pak, pak2.pak, players and video if present), and if present xatrix, rogue and ctf, side by side in a Quake II folder. On a CD they are often locked inside the installer: install the game on a PC then.

Quake III Arena and Team Arena

Copy baseq3 and, for Team Arena, missionpack, side by side. An original CD only has pak0.pk3 in baseq3: Borne offers the 1.32 update at first launch.

Return to Castle Wolfenstein

Copy the Main folder (pak0.pk3 and sp_pak1.pk3 to sp_pak4.pk3; the other files aren't needed). If you have two languages, put each in its own folder: Borne lists them separately.

Doom 3 and Resurrection of Evil

Copy the base folder (pak000.pk4 and following) and, for the add-on, d3xp, side by side in a Doom 3 folder. On a DVD they are in Setup/Data. The game00.pk4 file isn't needed. The 2012 “BFG Edition” isn't supported: you need the original 2004 version (with its base and d3xp folders).

Quake 4

Copy the q4base folder into a Quake 4 folder; on a DVD it is in Setup/Data. With a DVD, Borne offers the 1.4.2 update at first launch. Quake 4 requires an Apple silicon Mac.

Wolfenstein 3D and Spear of Destiny

Copy the .WL6 files (Wolfenstein 3D) or .SOD, .SD2, .SD3 (Spear of Destiny and its missions) into one folder per game. In the Steam versions they are often in a base subfolder. .WL1 files are the demo version.

Duke Nukem 3D, Blood, Shadow Warrior and the Build games

Copy the main file (DUKE3D.GRP, SW.GRP, REDNECK.GRP, STUFF.DAT…) into one folder per game. For Blood, copy the whole game folder: BLOOD.RFF needs the files around it. Raze, the engine for these games, downloads from Borne at first launch.

Checking

In Borne, each recognized game appears in its sidebar folder (Doom, Quake, Quake II…), with the number of games found. A game is missing? Check its file or folder name in the list of PC games, then rescan the folders (⌘R).
