PC games

The classics from id Software, 3D Realms and others aren't emulated: they run in modern, open-source engines that read the original data files. Borne picks the right engine, sets it up and launches it for you.

The games folder

Settings → Jeux PC → Ajouter un dossier… (Add a folder). One folder is enough, with a subfolder per game; subfolder names don't matter. Borne recognizes each game by its files: doom2.wad, Quake's id1 folder, Quake II's baseq2, DUKE3D.GRP… The list of PC games says exactly which files each game needs, and Preparing PC games explains step by step how to get and copy them.

Add-ons are grouped with their game: Scourge of Armagon and Dissolution of Eternity with Quake, The Reckoning and Ground Zero with Quake II, Team Arena with Quake III, Resurrection of Evil with Doom 3. For Doom, a mod .wad or .pk3 file is attached to its base game.

Add files at any time: Borne rescans the folder as soon as its contents change.

Where the game files come from

Borne doesn't provide any game. The data files come from your copy: the versions sold today on Steam and GOG include them, and so do the original CDs and DVDs. Copy the game's folder, or just its data files, into your PC games folder.

To try without buying anything: Freedoom, an entirely free Doom, downloads from Borne (Settings → Données).

The diagnostic

Each PC game's details end with a diagnostic: the engine, the game files, any update it needs and the files the game expects (such as Strife's or Quake 4's voices, or Wolfenstein 3D's files). Anything missing is explained, and a button completes it when Borne can: download an engine, install an id Software update.

Modules to download

Some parts can't be bundled with Borne for license reasons: openQ4 (Quake 4), Raze (the Build games), Freedoom, and three official id Software updates. Settings → Données lists them all with their status, and Tout télécharger (download all) installs them at once. Every file is checked against its fingerprint before it is installed, in your user folder.

If you launch a game whose module is missing, Borne offers it right then as well.

id Software's updates

The original discs of Quake III Arena, Doom 3 and Quake 4 predate these games' final updates, which modern engines need: Quake III 1.32, Doom 3 1.3.1, Quake 4 1.4.2. The Steam and GOG versions already include them.

These updates are covered by id Software's licenses: Borne only downloads them once you have accepted them, in Borne, and keeps only their data files. They are added to your game without changing your original files.

Saves and settings

Each engine keeps its saves, configuration and screenshots in your user folder (Settings → Données → Afficher dans le Finder), never next to the game files. In the game, Esc opens the menu: save, load, adjust picture and sound, quit.

Fire is also on X and the mouse click: Ctrl, the usual key on a PC, triggers macOS shortcuts when combined with the arrows.

Graphics

Recent engines draw with Vulkan, translated to Metal, the Mac's graphics interface: by KosmicKrisp on Apple silicon Macs with macOS 26, by MoltenVK elsewhere. Settings → Jeux PC → Pilote Vulkan de Quake lets you force MoltenVK if a game looks wrong.
