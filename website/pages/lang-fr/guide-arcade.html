L'arcade

Borne pilote MAME 0.289, inclus dans l'app. Il connaît toutes les machines de MAME ; celles dont vous avez les ROM sont dans le dossier Disponibles.

Les dossiers ROM

Réglages → Arcade → Dossiers ROM. Indiquez le dossier roms lui-même, ou le dossier qui le contient : Borne trouve roms à l'intérieur. Vos ensembles sont des fichiers .zip (un par jeu, avec le nom court de MAME, comme pacman.zip) ; les disques durs et CD des machines plus récentes sont des dossiers de fichiers .chd du même nom.

Ajoutez des ROM, puis relisez les dossiers : menu Jeux → Relire les dossiers de jeux (⌘R). Borne relit aussi tout seul quand le contenu d'un dossier change.

Un clone (une version régionale, une révision) a souvent besoin de son original, et certaines machines d'un BIOS : placez-les dans le même dossier. La fiche du jeu indique son original.

Trouver un jeu

  • Chercher : tapez une partie du titre, le nom court ou le fabricant dans le champ en haut à droite.
  • Trier : cliquez sur l'en-tête d'une colonne (jeu, année, fabricant, état…).
  • Filtrer : les dossiers de gauche — originaux ou clones, jeux fonctionnels, écran horizontal ou vertical, jeux qui savent sauvegarder — et Regrouper par fabricant, année, pilote ou processeur.
  • Favoris : l'étoile de la fiche (⌘D) ajoute le jeu au dossier Favoris.

La colonne État reprend le verdict de MAME : Bon le jeu tourne bien, Imparfait il est jouable avec des défauts (son, couleurs…), Préliminaire il ne fonctionne pas encore.

Les touches

Borne lance MAME avec une disposition pensée pour le clavier d'un Mac. La fiche de chaque jeu donne ses touches exactes ; en voici l'essentiel :

5Insérer une pièce
1Start, un joueur
← ↑ → ↓Joystick
Z X C V B NBoutons 1 à 6 du joueur 1
6 puis 2Pièce et Start du joueur 2 ; joystick sur R D F G, boutons sur A S Q W
SourisVolant, trackball ou pistolet
PPause
F12Capture d'écran (elle devient l'image du jeu dans la fiche)
ÉchapQuitter le jeu

Pourquoi pas Ctrl pour tirer, comme sur PC ? Sur Mac, Ctrl + flèche ouvre Mission Control ou change de bureau, en plein jeu. Les boutons sont donc sur Z X C…

Jouer sans le disque externe

Installer sur ce Mac…, dans la fiche, copie le jeu avec tout ce dont il a besoin : son original, son BIOS, ses périphériques et ses samples. La taille est annoncée avant la copie. Menu Jeux → Installer les favoris sur ce Mac… fait de même pour tous vos favoris.

Les copies locales passent toujours en premier : le jeu se lance même disque débranché. Elles sont dans le dossier Sur ce Mac ; Supprimer la copie les retire.

Diagnostiquer un jeu

Un jeu refuse de démarrer ? Dans sa fiche, Diagnostiquer demande à MAME tout ce dont il a besoin et le vérifie : le jeu lui-même, son original, son BIOS, ses périphériques, ses sons, puis chaque fichier. Chaque ligne dit ce qui est là (✓) et ce qui manque (✗), avec la marche à suivre : quel ensemble ajouter, lequel remplacer par sa version pour MAME 0.289. Les fichiers dont personne n'a jamais trouvé de bonne copie sont signalés comme tels : leur absence n'est pas de votre fait.

Vérifier ses ROM

Menu Jeux → Vérifier les ROM (⌘⇧R) demande à MAME de contrôler chaque ensemble présent. Le contrôle tourne en arrière-plan, les verdicts apparaissent au fil de l'eau, et ⌘. l'arrête quand vous voulez.

Images des jeux

La fiche montre une image du jeu : capture, écran-titre, fronton, flyer, borne ou panneau de commandes, au choix. Indiquez le dossier qui contient les sous-dossiers snap, titles, marquees, flyers, cabinets ou cpanel dans Réglages → Arcade → Images. Sans ces images, F12 pendant le jeu en crée une.

Affichage et réglages d'un jeu

  • Rendu : Réglages → Général → Rendu de MAME, Metal (bgfx, par défaut) ou OpenGL.
  • Options en plus : le champ du même nom passe des options à MAME, par exemple -bgfx_screen_chains crt-geom pour l'effet d'un écran cathodique.
  • Un écran décalé ou déformé ? Le menu de MAME (Tab) a pu modifier l'affichage du jeu. Dans la fiche, Réinitialiser l'affichage efface ce réglage-là et rien d'autre ; Réinitialiser tous les réglages… remet le jeu comme neuf (sans toucher à ses sauvegardes).
