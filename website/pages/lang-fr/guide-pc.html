Les jeux PC

Les classiques d'id Software, de 3D Realms et des autres ne s'émulent pas : ils tournent dans des moteurs modernes, libres, qui lisent les fichiers de données d'origine. Borne choisit le bon moteur, le règle et le lance pour vous.

Le dossier des jeux

Réglages → Jeux PC → Ajouter un dossier…. Un seul dossier suffit, avec un sous-dossier par jeu ; le nom des sous-dossiers ne compte pas. Borne reconnaît chaque jeu à ses fichiers : doom2.wad, le dossier id1 de Quake, baseq2 de Quake II, DUKE3D.GRP… La liste des jeux PC dit exactement quels fichiers chaque jeu demande, et Préparer les jeux PC explique pas à pas comment les obtenir et les copier.

Les extensions sont rangées avec leur jeu : Scourge of Armagon et Dissolution of Eternity avec Quake, The Reckoning et Ground Zero avec Quake II, Team Arena avec Quake III, Resurrection of Evil avec Doom 3. Pour Doom, un fichier .wad ou .pk3 de mod est rattaché à son jeu de base.

Ajoutez des fichiers à tout moment : Borne relit le dossier dès que son contenu change.

D'où viennent les fichiers de jeu

Borne ne fournit aucun jeu. Les fichiers de données viennent de votre copie : les versions vendues aujourd'hui sur Steam et GOG les contiennent, les CD et DVD d'origine aussi. Copiez le dossier du jeu, ou seulement ses fichiers de données, dans votre dossier de jeux PC.

Pour essayer sans rien acheter : Freedoom, un Doom entièrement libre, se télécharge depuis Borne (Réglages → Données).

Le diagnostic

La fiche de chaque jeu PC se termine par un diagnostic : le moteur, les fichiers du jeu, la mise à jour éventuellement nécessaire et les fichiers que le jeu attend (par exemple les voix de Strife ou de Quake 4, ou les fichiers de Wolfenstein 3D). Ce qui manque est expliqué, et un bouton le complète quand Borne peut le faire : télécharger un moteur, installer une mise à jour d'id Software.

Les modules à télécharger

Certains éléments ne peuvent pas être inclus dans Borne, pour des raisons de licence : openQ4 (Quake 4), Raze (les jeux Build), Freedoom, et trois mises à jour officielles d'id Software. Réglages → Données les liste tous, avec leur état, et Tout télécharger les installe en une fois. Chaque fichier est vérifié par son empreinte avant d'être installé, dans votre dossier utilisateur.

Si vous lancez un jeu dont le module manque, Borne vous le propose aussi à ce moment-là.

Les mises à jour d'id Software

Les disques d'origine de Quake III Arena, Doom 3 et Quake 4 datent d'avant les dernières mises à jour de ces jeux, et les moteurs modernes en ont besoin : Quake III 1.32, Doom 3 1.3.1, Quake 4 1.4.2. Les versions Steam et GOG les contiennent déjà.

Ces mises à jour sont soumises aux licences d'id Software : Borne ne les télécharge qu'une fois que vous les avez acceptées, dans Borne, et n'en garde que les fichiers de données. Elles s'ajoutent à votre jeu sans modifier vos fichiers d'origine.

Sauvegardes et réglages

Chaque moteur range ses sauvegardes, sa configuration et ses captures dans votre dossier utilisateur (Réglages → Données → Afficher dans le Finder), jamais à côté des fichiers de jeu. Dans le jeu, Échap ouvre le menu : sauvegarder, charger, régler l'image et le son, quitter.

Le tir est aussi sur X et sur le clic de la souris : Ctrl, la touche habituelle sur PC, déclenche des raccourcis de macOS quand on la combine avec les flèches.

Graphismes

Les moteurs récents dessinent en Vulkan, traduit vers Metal, l'interface graphique du Mac : par KosmicKrisp sur Mac Apple silicon avec macOS 26, par MoltenVK ailleurs. Réglages → Jeux PC → Pilote Vulkan de Quake permet de forcer MoltenVK si un jeu s'affiche mal.
