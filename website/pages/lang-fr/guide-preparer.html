Préparer les jeux PC

Borne ne lit pas les installeurs ni les disques : il lit les fichiers de données d'un jeu déjà installé. Cette page explique comment les obtenir à partir de votre copie, quels fichiers copier et où les ranger. On ne le fait qu'une fois par jeu.

Le principe

Un jeu PC se compose d'un programme Windows ou DOS (.exe, .dll), qui ne sert pas sur Mac, et de fichiers de données (niveaux, images, sons) : .wad, .pak, .pk3, .pk4, .grp… Ce sont ces derniers que les moteurs de Borne lisent. Il suffit donc de les copier, en gardant le nom de leur dossier quand ils en ont un (id1, baseq2, baseq3…).

Copier aussi le reste n'est pas grave, Borne l'ignore ; mais un dossier ne contenant que les données est plus léger et plus clair.

Le rangement à obtenir

Créez un dossier pour vos jeux PC, par exemple Jeux PC sur votre disque externe, avec un sous-dossier par jeu. Le nom des sous-dossiers est libre ; seuls comptent les fichiers et les dossiers de données à l'intérieur. Majuscules et minuscules sont indifférentes.

Jeux PC/
├── Doom/                       doom.wad, doom2.wad, tnt.wad, plutonia.wad,
│                               heretic.wad, hexen.wad, strife1.wad…
├── Quake/
│   ├── id1/                    pak0.pak, pak1.pak
│   ├── hipnotic/               pak0.pak   (Scourge of Armagon)
│   └── rogue/                  pak0.pak   (Dissolution of Eternity)
├── Quake II/
│   ├── baseq2/                 pak0.pak, pak1.pak, pak2.pak, players/, video/
│   ├── xatrix/                 pak0.pak   (The Reckoning)
│   ├── rogue/                  pak0.pak   (Ground Zero)
│   └── ctf/                    pak0.pak   (Capture The Flag)
├── Quake III Arena/
│   ├── baseq3/                 pak0.pk3 … pak8.pk3
│   └── missionpack/            pak0.pk3 … (Team Arena)
├── Quake 4/
│   └── q4base/                 pak001.pk4 … pak022.pk4, zpak_english.pk4
├── Doom 3/
│   ├── base/                   pak000.pk4 … pak008.pk4
│   └── d3xp/                   pak000.pk4, pak001.pk4   (Resurrection of Evil)
├── Return to Castle Wolfenstein/
│   └── Main/                   pak0.pk3, sp_pak1.pk3 … sp_pak4.pk3
├── Wolfenstein 3D/             VSWAP.WL6, GAMEMAPS.WL6, MAPHEAD.WL6, AUDIOT.WL6…
├── Spear of Destiny/           VSWAP.SOD, GAMEMAPS.SOD… (et .SD2, .SD3)
└── Duke Nukem 3D/              DUKE3D.GRP

Puis, dans Borne : Réglages → Jeux PC → Ajouter un dossier… et choisissez Jeux PC. C'est tout : chaque jeu apparaît dans la barre de gauche.

Où trouver les fichiers

Une version Steam

Ces jeux sont des jeux Windows : Steam pour Mac les affiche dans la bibliothèque, mais ne les installe pas. Installez-les avec Steam sur un PC Windows (le vôtre, celui d'un proche, une machine virtuelle), puis, dans la bibliothèque Steam : clic droit sur le jeu → Gérer → Parcourir les fichiers locaux. Le dossier qui s'ouvre (en général …\Steam\steamapps\common\<nom du jeu>) contient les données décrites plus bas.

Les versions Steam sont déjà à jour : Quake III, Doom 3 et Quake 4 n'ont pas besoin des mises à jour d'id Software.

Une version GOG

Deux possibilités :

  • Sur un PC Windows : installez le jeu avec GOG Galaxy ou l'installeur hors ligne, puis copiez le dossier d'installation (par défaut C:\GOG Games\<nom du jeu>).
  • Directement sur le Mac, sans Windows : téléchargez depuis votre compte GOG l'installeur hors ligne pour Windows (setup_….exe, et ses fichiers .bin s'il y en a, rangés à côté). L'outil libre innoextract en extrait les fichiers. Dans le Terminal : 
    brew install innoextract
cd ~/Downloads
innoextract setup_quake_the_offering_*.exe
    Les fichiers du jeu apparaissent dans un dossier app (ou à la racine du dossier) : copiez-y les données. Il faut Homebrew ; les installeurs GOG les plus récents peuvent ne pas s'ouvrir avec la version actuelle d'innoextract : passez alors par un PC.

Un CD ou un DVD d'origine

Insérez le disque, ou ouvrez son image (.iso) d'un double-clic : macOS l'affiche comme un disque. Deux cas :

  • Les données sont visibles sur le disque, souvent dans un dossier Setup/Data ou à la racine (par exemple Setup/Data/base pour Doom 3, Setup/Data/q4base pour Quake 4) : copiez-les simplement.
  • Seul un installeur est visible (setup.exe, fichiers .cab ou .msi) : les données sont compressées dedans. Installez le jeu sur un PC Windows, puis copiez le dossier installé (en général dans C:\Program Files ou C:\Program Files (x86)).

Un disque d'origine date souvent d'avant la dernière mise à jour du jeu. Pour Quake III, Doom 3 et Quake 4, Borne vous proposera la mise à jour officielle au premier lancement : copiez les fichiers du disque tels quels.

Copier sur le Mac

Par une clé USB, un disque externe ou le réseau (Finder → Aller → Se connecter au serveur, pour un partage Windows smb://). Copiez les dossiers entiers (id1, baseq2…) plutôt que leur contenu, pour garder leur nom. Les fichiers peuvent ensuite rester sur un disque externe : Borne ne les modifie jamais.

Jeu par jeu

Ce qu'il faut copier depuis le dossier d'installation du jeu, et où le ranger dans votre dossier Jeux PC. En cas de doute, cherchez le nom du fichier dans le Finder (⌘F dans le dossier du jeu).

Doom, Doom II, Final Doom, Heretic, Hexen, Strife

Copiez les fichiers .wad du jeu (doom.wad, doom2.wad, tnt.wad, plutonia.wad, heretic.wad, hexen.wad, hexdd.wad, strife1.wad avec voices.wad) dans un même dossier Doom. Dans les versions Steam et GOG, ils sont dans le dossier du jeu ou dans un sous-dossier comme base ou rerelease. Vos mods (.wad, .pk3) vont dans le même dossier.

Pas de copie de Doom ? Freedoom, libre et complet, se télécharge depuis Borne (Réglages → Données).

Quake et ses extensions

Copiez le dossier id1 (pak0.pak et pak1.pak), et s'ils y sont hipnotic et rogue, côte à côte dans un dossier Quake. La version Steam de 2021 range le jeu d'origine dans ces dossiers ; son dossier rerelease n'est pas nécessaire. Un id1 sans pak1.pak est la version de démonstration.

Quake II et ses extensions

Copiez le dossier baseq2 (au moins pak0.pak ; aussi pak1.pak, pak2.pak, players et video s'ils y sont), et s'ils y sont xatrix, rogue et ctf, côte à côte dans un dossier Quake II. Sur un CD, ils sont souvent enfermés dans l'installeur : installez alors le jeu sur un PC.

Quake III Arena et Team Arena

Copiez baseq3 et, pour Team Arena, missionpack, côte à côte. Un CD d'origine n'a que pak0.pk3 dans baseq3 : Borne propose la mise à jour 1.32 au premier lancement.

Return to Castle Wolfenstein

Copiez le dossier Main (pak0.pk3 et sp_pak1.pk3 à sp_pak4.pk3, les autres fichiers sont inutiles). Si vous avez deux langues, mettez chacune dans son propre dossier : Borne les présente séparément.

Doom 3 et Resurrection of Evil

Copiez le dossier base (pak000.pk4 et suivants) et, pour l'extension, d3xp, côte à côte dans un dossier Doom 3. Sur un DVD, ils sont dans Setup/Data. Le fichier game00.pk4 est inutile. La « BFG Edition » de 2012 n'est pas prise en charge : il faut la version d'origine de 2004 (avec ses dossiers base et d3xp).

Quake 4

Copiez le dossier q4base dans un dossier Quake 4 ; sur un DVD, il est dans Setup/Data. Avec un DVD, Borne propose la mise à jour 1.4.2 au premier lancement. Quake 4 demande un Mac Apple silicon.

Wolfenstein 3D et Spear of Destiny

Copiez les fichiers .WL6 (Wolfenstein 3D) ou .SOD, .SD2, .SD3 (Spear of Destiny et ses missions) dans un dossier par jeu. Dans les versions Steam, ils sont souvent dans un sous-dossier base. Les fichiers .WL1 sont ceux de la version de démonstration.

Duke Nukem 3D, Blood, Shadow Warrior et les jeux Build

Copiez le fichier principal (DUKE3D.GRP, SW.GRP, REDNECK.GRP, STUFF.DAT…) dans un dossier par jeu. Pour Blood, copiez tout le dossier du jeu : BLOOD.RFF a besoin des fichiers qui l'entourent. Raze, le moteur de ces jeux, se télécharge depuis Borne au premier lancement.

Vérifier

Dans Borne, chaque jeu reconnu apparaît dans son dossier de la barre de gauche (Doom, Quake, Quake II…), avec le nombre de jeux trouvés. Un jeu manque ? Vérifiez le nom de son fichier ou de son dossier dans la liste des jeux PC, puis relisez les dossiers (⌘R).
