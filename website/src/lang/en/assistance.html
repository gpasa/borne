Answers to the questions people ask most often. For anything else, write to us on GitHub.

Frequently asked questions

Does Borne include any games?

No, none. Borne, MAME and the engines are software; arcade ROMs and PC game files are up to you. Only use those you are entitled to. Freedoom, an entirely free Doom, downloads from Borne.

Is the app available in English?

Not yet: Borne's interface is in French for now. This guide names each menu and button as it appears in the app, with its meaning.

An arcade game isn't in “Disponibles”

Check that its .zip file has MAME's short name (shown in the game's details under Nom court) and is in a ROM folder set in the settings. Then rescan the folders (⌘R). A clone needs its parent, a machine its BIOS: keep them alongside.

An arcade game starts and closes right away

In its details, Diagnostiquer (diagnose) says exactly what is missing and how to complete it. A file is often missing: a BIOS, a clone's parent, or a set from another MAME version. Jeux menu → Vérifier les ROM gives MAME's verdict for each game. Borne uses MAME 0.289: your sets must match that version.

A game's picture is shifted or distorted

MAME's menu (Tab) may have changed its display. In the game's details, Réinitialiser l'affichage puts the picture back without touching anything else.

Keys don't respond, or Ctrl switches desktops

On a Mac, Ctrl + arrow belongs to Mission Control. So Borne puts the arcade buttons on Z X C V B N, and fire on X or the click for PC games. Each game's details list its keys.

A PC game doesn't show up

Check that its folder is in Settings → Jeux PC and that its data files are there: the list of PC games says which. Installer files (setup.exe, disc images, archives) aren't enough: you need the installed files.

Borne offers me an id Software update

Your copy comes from an original disc, older than the game's last update, which the modern engine needs. Read the license and accept it if you agree: Borne downloads the official update, checks its fingerprint and keeps only its data, in your user folder.

macOS asks for Accessibility access for Borne

Borne doesn't need it: decline. Versions 1.3.2 and later no longer trigger this request; if you had granted it, you can remove Borne from System Settings → Privacy & Security → Accessibility.

What about Intel Macs?

There is an Intel version, native too. Quake 4 (openQ4) is for Apple silicon Macs only. macOS 14 or later is required.

Reporting a problem

Open an issue on GitHub: describe the game, what you expected and what happened, and mention your Mac and your macOS version. Ideas are welcome in the same place.

Privacy

Borne collects nothing and sends nothing. It only goes online when you ask for a module (Freedoom, Raze, openQ4, an id Software update), from its official source or a copy on GitHub, and checks every file against its fingerprint. Your games, saves and settings stay on your Mac.
